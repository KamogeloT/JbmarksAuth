# Assets Directory

This directory contains all static assets for the JBmarks mobile app.

## Required Files

- `icon.png` - App icon (1024x1024)
- `adaptive-icon.png` - Android adaptive icon
- `splash-icon.png` - Splash screen icon
- `favicon.png` - Web favicon
- `jbmarkslogo.jpg` - JBmarks logo

## Notes

Make sure all image assets are properly sized and optimized for mobile devices.
